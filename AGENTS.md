## Hostnames

**Hardware nodes** use apartment features. VMs and CTs use character first names. Lowercase, hyphenated if needed. One name per host. Do not reuse a taken name.

**Nodes** — set pieces, not people: beige-carpet, purple-walls, ugly-naked-guy, hall-closet. Small or storage nodes get small places (hall-closet, spice-rack).

**VMs / CTs** — character only: gunther, pete, heckles, tag. Match personality to the job, not the plot.

**Description** — one or two sentences. Role first, then the character parallel.

```markdown
Gunther

The quiet manager everything has to pass through. VPN and HTTP proxy — always watching, slightly judgmental, nothing in or out without him.
```
